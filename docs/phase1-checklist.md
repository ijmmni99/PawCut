# Phase 1 — iPhone test checklist

Pass: edit a 3-min clip into 30s and export on iPhone without lag.

- [ ] Open PawCut from the Home Screen; tap **Update** if the bar appears
- [ ] New project → pick a **3-min default-camera (HDR) clip**; "Preparing %" advances, thumbnails appear
- [ ] HDR colour: preview vs Photos — washed out / grey?
- [ ] Drag + pinch the timeline: smooth? preview follows the finger closely?
- [ ] Cut to ~30s with Split / Delete / trim handles; set one piece to 2×; long-press to reorder two clips
- [ ] Play: cuts seamless (no black flash), sound continues after each cut
- [ ] Export → Save Video → plays in Photos → uploads to TikTok; note the "Took" time
- [ ] Mid-edit, swipe PawCut away in the app switcher, reopen: edits and undo history still there
