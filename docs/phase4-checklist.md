# Phase 4 — iPhone test checklist

Pass: 30s voiceover video → styled word-pop captions in ≤3 taps.

- [ ] Open a project with someone talking (or record a voiceover over a clip)
- [ ] **Captions** → **Generate captions** (2 taps). First time: "Downloading speech model… %" (~80 MB, Wi-Fi
      recommended), then "Listening…". Later runs skip the download and work offline
- [ ] Play: words pop in 2 at a time, white with black outline; keywords (numbers, FREE, cat…) in yellow, 😺 after "cat"
- [ ] Tap the captions row on the timeline → **Edit captions**: try Karaoke (active word pink box), Bold Outline,
      Keyword — each restyles everything in one tap
- [ ] Fix a misheard word in the list → timing stays; ✂︎ split a caption at a word; ⤓ merge with the next; ✕ delete
- [ ] Position Top / Middle / Bottom; 1 vs 2 lines; characters slider; Emoji on/off
- [ ] Malay or Mandarin clip: pick the language (or Auto) → captions in that language (中文 uses the system font)
- [ ] No speech? **Type captions instead** → one caption per line, spread across the video
- [ ] **Text** → type → pick font (6 fonts), colour, Outline/Shadow/Box/Glow, size, In/Out/Loop animations → Done
- [ ] On the preview: drag the text (snaps to centre), pinch to resize/rotate; on the timeline: drag/trim its block
- [ ] Safe-zone button (top-right of preview) shows where TikTok's UI covers the video — captions sit inside
- [ ] Export → captions and text are burnt in exactly as previewed (Photos + TikTok)
- [ ] Note how long "Listening…" takes for a 30s clip (target well under a minute)
